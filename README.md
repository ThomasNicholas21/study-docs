# Respositório para documentar  📚

Este repositório tem como finalidade documentar estudos sobre programação, abordando diversos temas da área, com o objetivo de aprofundar o conhecimento, primeiramente, em '`Python`'. Alguns temas podem ser abrangentes e se encaixarem com outras linguagens.

Como o foco é aprofundar ao máximo em '`Python`', haverá diversas abordagens e exemplos sobre a linguagem. No entanto, isso não significa que será especificamente sobre essa linguagem; futuramente, haverá conteúdos mais abrangentes sobre outras tecnologias.


# Repository for Documenting Studies  📚

The purpose of this repository is to document studies on programming, covering various topics in the field, with the primary goal of deepening knowledge in '`Python`'. Some topics may be broad and apply to other languages.

As the focus is to delve as deeply as possible into '`Python`', there will be various approaches and examples related to the language. However, this does not mean it will be exclusively about this language; in the future, there will be more comprehensive content on other technologies.
